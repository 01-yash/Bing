# Cake imagery

`classic-birthday-cake.webp` and `custom-floral-cake.webp` were generated specifically for this demonstration. They show a simple classic buttercream birthday cake and a more intricate custom floral design. They are not photographs of Bing’s Bakery products or a promise that a particular design is available.

`homepage-celebration-cake.webp` is a matching generated hero image of an ivory buttercream cake with blush flowers, shown in the homepage’s arched frame. It is also a design example rather than a photograph of an actual Bing’s product.

The original generated images were encoded as WebP for efficient local delivery. All assets are bundled with the website; no external photo service is required.
