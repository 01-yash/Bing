# Cake card images

`classic-birthday-cake.webp` and `custom-floral-cake.webp` were generated specifically for this demonstration. They show a simple classic buttercream birthday cake and a more intricate custom floral design. They are not photographs of Bing’s Bakery products or a promise that a particular design is available.

The original generated images were encoded as WebP for efficient local delivery. Both assets are bundled with the website; no external photo service is required.
